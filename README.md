# HTML: Console OS

------------------------------------------------------------
This is a Operating System that runs off of any browser.
------------------------------------------------------------

It is undetectable and un-seeable by all monitering systems in browsers, internet or as extensions. It is one of the largest, most well made game repository with a garuntee of working links.

# Features:

-Custom Backgrounds. Choose from presets, from links or upload your own.

-Dark & Light mods.

-Custom accent colors. Choose from presets or color pick your own.

-Differing clock formats, differing desktop icon sizes.

-Themes: Save your own themes.

-Sound & Audio for the whole OS.

-Real-time localstorage and IndexedDB storage that everything saves to.

-An update feature that allows you to download newest versions from this Github straight from your copy of the file.

-An Appstore, as well as other preset desktop icons.

-A cross-device chat feature, with a profanity filter.

-A actual File Manager bundled with a working text editor.

-A full on Windows 11 Context menu with lots of options.

-The ability to create folders, drag icons into folders and drag icons anywhere on desktop.

-Notifications and notification tray.

-Search bar to search through all games.

-The "Start Menu" where all games an apps are located.

-Hovering over an minimzed app shows you a preview of it.

-You can pin/unpin apps and add/remove apps from desktop.

-You can rename all desktop apps.
